<h2>📱 About This Project</h2>

<p>
This project focuses on analyzing mobile phone specifications and building
Machine Learning models to classify mobile phones based on their features.
</p>

<p>
The project contains two separate datasets:
<strong>Train</strong> and <strong>Test</strong>.
Both datasets were completely cleaned and prepared to ensure they were ready
for the modeling stage.
</p>

<p>
Three different Classification models were then applied:
<strong>Decision Trees (DTs), Random Forest (RF), and Support Vector Machine (SVM)</strong>.
</p>

</div>

<div style="background:linear-gradient(135deg,#faf5ff,#e9d5ff); border:1px solid #b784e6; border-radius:20px; padding:25px; margin:25px 0;">

<h2>🎯 Project Goal</h2>

<p>
The main goal of this project is to use mobile phone specifications to build
Classification models capable of predicting the appropriate mobile price category.
</p>

<p>
This type of analysis can be useful for companies that want to study their own
products alongside competitors' products and better understand how different
device specifications relate to their market positioning.
</p>

</div>

Before applying Machine Learning algorithms, both the Train and Test datasets
